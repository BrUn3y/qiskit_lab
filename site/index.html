[ 05 — FIELD NOTES ]A FEW THINGS TO KNOW

GOOD
QUESTIONS.

Do I need access to a quantum computer?+

No. Local statevector simulation works without IBM credentials. Hardware execution requires an IBM Quantum account, access to a backend, and your explicit choice to submit a job.

What is DAM’s role?+

DAM provides the model, agent harness, and workspace. Qiskit Lab is a native Python package that uses the Qiskit SDK directly for its quantum operations.

What do I get after an experiment?+

Completed local runs produce an HTML report and scientific receipts, plus circuit and visualization assets. Terminal hardware jobs produce reports with their recorded status and available results. Queued jobs retain their job ID for later inspection.

Is the playground running Qiskit?+

The website playground uses ideal, analytically specified probabilities and browser random sampling for three fixed examples. It does not execute Qiskit or contact IBM. Install Qiskit Lab to run and report actual Qiskit experiments.
